Install

NoteDrifter ships as a single binary for macOS, Windows, and Linux. Pick a build, drop it in your apps folder, and launch.

brew install --cask notedrifter
# or
curl -fsSL https://notedrifter.app/install.sh | sh

First launch downloads the visualization pack (~280 MB). You can swap packs later from Preferences → Visuals.

Your first render

  1. Drag a .mid or .musicxml file onto the NoteDrifter window.
  2. Pick a preset from the Visualizer panel — try Drift or Aurora.
  3. Hit the big Render button. NoteDrifter encodes a 4K H.265 video and a transparent PNG sequence in parallel.

Tracks & layers

Each MIDI track becomes a layer in the timeline. Layers stack along the Z axis — the topmost layer renders closest to the camera.

  • Solo / Mute — toggle visibility per layer without altering the source.
  • Velocity → opacity — softer notes fade by default, configurable per layer.
  • Channel routing — split a single MIDI channel into multiple visual layers via key range.

Color system

Every line of every layer can be its own color. NoteDrifter uses an HSL palette internally so gradients between voices stay perceptually even.

Bring your own palette with palette.toml — see the Library chapter.

Orientation

Notes can rise, fall, sweep horizontally, or swirl around a focal point. Change orientation under View → Camera or with the keyboard.

↑ Rise

Default — notes climb from the keyboard.

↓ Fall

Classic Synthesia look. Notes descend to the keys.

→ Sweep

Time travels left-to-right; great for studio loops.

⟳ Orbit

Notes circle a center; cinematic for chordal pieces.

Exports

Pick what you need at render-time. Multiple targets render simultaneously when your machine can keep up.

  • Video — H.264 / H.265 / ProRes 4444 with optional alpha.
  • Image sequence — PNG, EXR, or WebP at any frame rate.
  • Live embed — copy a snippet that runs on any web page (it powers the demo on the home page).

Library

The Library is a tagged grid of presets, palettes, and reusable pieces of motion. Drop any project into the Library to share it across machines or with your team.

A preset is just a folder of TOML files; revision-control it like code.
