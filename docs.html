Welcome

NoteDrifter is an AI-assisted piano visualization tool. It turns a MIDI file (or any track with detectable notes) into a clean, animated piano video — keys lit, falling note bars, soft glow, synced to the second. Every visual decision — colors per instrument, key tinting, scroll direction, camera angle, speed, background — is exposed in a single Configurations panel.

These docs walk through the app in the same order you'll meet it: get in, open a project, tune the look, render.

Install & sign in

Open the desktop app or visit the web build, then choose Sign up for free. You'll be asked for an email, a password, and a confirmation. Existing users can switch to Login from the same screen.

Your library, custom palettes, and unfinished projects all sync to your account. You can sign in on a new machine and pick up right where you left off.

Your first render

The fastest path from "open the app" to "video file":

  1. From Get Started, drop a MIDI or audio file onto Drop a File in — or click Upload a File.
  2. Click Design your own style.
  3. In the editor, tap the Play button to preview. The piano lights up, bars rise, and the timeline scrubs along.
  4. When you're happy, hit Export in the top-right. NoteDrifter renders a 1080p MP4 by default.

That's it — you have a finished music video. Everything below is about tuning how it looks.

New project

From the dashboard, click New in the top-right. You'll see two paths:

  • Create a new project from scratch — start with a blank canvas. NoteDrifter generates a sensible style from your uploaded track and visualization seed.
  • Import a project — bring in an existing .ndrift file from a friend or your library. Everything (parts, palettes, angle, speed) is preserved.

Dashboard

The left sidebar holds five tabs: Dashboard, Projects, Design, Preferences, Settings. New users land on No Projects Yet with a single Create a new one action — clicking it opens the New Project flow.

Design stores reusable style packs. Preferences controls editor behavior (theme, default note speed, render directory). Settings is account-level (email, password, plan).

The editor

Every project opens in the editor. Top of the screen: a piano keyboard mirroring the playhead. Above it: rising note bars. Bottom of the screen: the timeline, plus transport (play, previous, next, fullscreen).

Two icons sit in the lower-right: a gear opens Configurations, and the fullscreen arrows toggle a distraction-free preview.

Tip — drag the playhead anywhere on the timeline; the keys and bars update instantly. Useful for spot-checking a single bar.

Project vs. Part Settings

Configurations has two tabs at the top: Project Settings and Part Settings.

  • Project Settings apply to the whole video — note speed, background, default angle.
  • Part Settings apply per instrument layer — note color and key color for Instrument 1, Instrument 2, and so on. Each part can also have a longer descriptive name (visible as "Instrument Long Long Long Name" in the panel).

Note color

Under Style → Note Color you'll see one row per instrument with a colored swatch on the right. Click a swatch to recolor every rising bar belonging to that instrument. Use the « and » arrows to swap with the row above or below.

Key color

Under Key Color you can give each instrument its own tint when notes land on the keys at the bottom of the screen. The Match Note Color toggle is a shortcut: when on, key tint mirrors the note color above. Turn it off for independent control — e.g. white bars with red key flashes.

Direction & angle

Note bars usually rise upward, but you can change the Direction per row. Combined with Angle (default 25.00°), you can pitch the camera in any plane — from a flat front view (0°) to the dramatic angled sheet shown in Editor Examples.

↑ Up

Default. Bars rise from keys.

↓ Down

Bars fall onto keys from above.

↗ Angle

Pitched plane (set Angle in degrees).

Note speed

Note Speed controls how fast bars travel between spawning at the top and landing on the keys. The default is 25.00. Higher values feel urgent and percussive; lower values feel cinematic and meditative. For ambient piano pieces, try 12–16.

Background

The Background dropdown has two modes:

  • Image — pick a photo or palette from your library. Crystal shards, deep gradients, and abstract noise tile cleanly behind the bars.
  • Color — solid background. Use this when note color is doing the heavy lifting and you want clean negative space.

Export

From the editor, click Export. NoteDrifter renders an MP4 at the resolution and aspect ratio set in Preferences (default 1920×1080, 60fps). Render time scales linearly with project length and quality. 

# Common export targets
1920 × 1080  · 60fps  · h264   — YouTube
1080 × 1920  · 60fps  · h264   — Reels / Shorts / TikTok
2560 × 1440  · 60fps  · h264   — Premium & thumbnails
3840 × 2160  · 60fps  · prores — Master / archive
